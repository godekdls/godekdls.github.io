Spring for Apache Kafka는 스프링의 핵심 개념을 이용해 카프카 기반의 메시지 처리 솔루션을 개발할 수 있게 도와주는 프로젝트다. Spring for Apache Kafka가 제공하는 "템플릿"은 메시지 전송 기능을 높은 수준으로 추상화한다. 또한 메시지 지향<sup>Message-driven</sup> POJO도 지원하고 있다.
